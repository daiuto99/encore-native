Design Philosophy

Built different, on purpose.

Four principles that define how KAI works — and what it refuses to be.

01

JARVIS DNA

KAI never says "I can't." Every limitation is a solvable engineering problem. The answer is always the path — what's blocking, what we'd need, how to build it.

02

Council, Not Chatbot

Ten specialized advisors with defined personas, domains, and model assignments. Each one is a distinct intelligence, not a mode switch. The right advisor gets the right question.

03

Memory That Works

A structured vault — persistent across all sessions, synced to Obsidian, Docker volume-mounted into every container. KAI doesn't start from scratch. Ever.

04

Tiered Governance

T1 autonomous, T2 Slack-approval, T3 typed confirmation. Nothing sends email without explicit approval. KAI executes — but Leo stays in control of the blast radius.

How KAI Runs Your Life

Not a chatbot.
An operating system.

KAI manages structured domains — each with its own data model, memory, and workflow. Projects run like a real company. Life runs like a system.

📋
Projects
Managed Like a Real Company

Every project lives in Plane — the project management layer KAI uses to track issues, sprints, and decisions. No rogue development. If it's not in Plane, it doesn't exist. KAI reads the board, writes back to it, and reports on it.

Slack · Like a Real Team
Each project has its own Slack channel. Updates, decisions, and session notes post automatically. The team stays informed without anyone manually updating.
Session Notes & Decisions
Every session closes with structured notes written to the vault. Decisions get their own log. Nothing lives only in someone's head.
Memory & Context
Each project has its own STATUS.md, knowledge files, and context loaded into advisors when relevant. KAI never starts a project conversation cold.
✅
Tasks
Daily Execution Layer

Task management integrated with Plane, surfaced every morning in the brief. KAI knows what's due, what's blocked, and what slipped — and names it before you ask.

  • Morning brief surfaces today's priority tasks
  • Linked to project sprints in Plane
  • KAI notices and flags what's slipping
  • Completion logged to vault for pattern tracking
🌊
Harmony
Life Tracking System

A structured daily check-in system that tracks energy, mood, sleep quality, and readiness across time. The operating layer for understanding how you're actually doing.

  • Daily log: energy, mood, focus, notes
  • Integrates Oura Ring sleep + readiness data
  • Trends surfaced by Doc and Coach advisors
  • Synced to vault — full history preserved
🔥
Habits
Consistent System Wins

Habit tracking built into the daily brief. KAI doesn't nag — it reflects. Streaks, patterns, and gaps are surfaced when they matter, not as a guilt dashboard.

  • Morning brief shows today's habit targets
  • Evening brief confirms completion
  • Streak data and trends in vault
  • Coach advisor reviews weekly patterns
💡
Parking Lot
No Idea Gets Lost

Ideas, gear, projects, and concepts that aren't active yet but matter. The parking lot is structured — tagged, searchable, and surfaced when context makes them relevant.

  • Categorized: gear / projects / ideas / references
  • KAI surfaces items when relevant context arises
  • Links to Plane for when it becomes a real project
  • Advisors can add to it directly from chat

What's Next

This is the foundation.
Not the ceiling.

KAI is a platform in the truest sense — every capability added creates compounding leverage across everything else. These are the next layers.

NEXT

Daily Rhythm Loop

Morning check-in → intention → tasks → evening reflection. A daily operating loop that KAI runs, not just responds to. The briefs are the first layer. The loop is the goal.

NEXT

Full Health Intelligence

Apple Health integration, Dexcom CGM data, and Oura Ring unified into a single health layer. Doc becomes the most data-rich advisor on the board — real-time, longitudinal, actionable.

NEXT

Semantic Memory (RAG)

Vector embeddings across the full vault. Any advisor can semantically search years of sessions, decisions, and knowledge files. The difference between looking something up and actually knowing it.

HORIZON

AI Avatar Layer

Sky was always meant to be seen. KAI was designed to be heard. The council becomes a visible, speakable presence — driven by the same council API that runs today. This presentation is the prototype.

HORIZON

CREATE Pipeline

Podcast → transcript → blog → social → Beehiiv. A full content intelligence layer that turns long-form output into distributed content automatically. LaunchBox becomes the production engine.

HORIZON

Proactive KAI

KAI initiates, not just responds. Accountability loops, project nudges, opportunity flags — the shift from reactive assistant to proactive chief of staff is the final unlock.

The design principle that holds: Every tool added increases the leverage of every other tool. The git tracker posts to Slack which the briefs can read. The GPS feeds the weather which feeds the brief. The vault holds everything. The RAG layer will make it all searchable. It compounds.
